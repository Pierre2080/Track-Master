## Descrição
O principal objetivo é criar uma experiência personalizada que combine a organização de conteúdos de entretenimento com a descoberta de novas obras e a interação entre utilizadores.
## Objetivos
- criar uma biblioteca pessoal para poder controlar o que ver e jogar
- criar comunidades sobre o que gostamos
- interagir com outros utilizadores
